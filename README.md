Este es un software creado a la medida de los archivos generados por el equipo MEATROL_ME435. 
El fin de este software es capturar los datos del CSV generado por el equipo y mostrarlos con
una interfaz adecuada con capacidad visualizar los datos de manera eficiente y ordenada.
Las capacidades de este software son :
  Ver las gráficas de los datos
  Hacer zoom sobre tiempos específicos
  Lanzar varios gráficas sobre un mismo parámetro
  En corrientes ver los diagramas fasoriales
  En armónicos poder ver el espectro en determinado punto de tiempo
  Generar un informe de lo que se tiene en pantalla al momento de solicitarlo
  Exportar en png cualquier gráfico en estudio
  Guardar el proyecto para recuperarlo luego.

El software se puede usar totalmente gratis. Esta pensado para uso solo con el ME435.
